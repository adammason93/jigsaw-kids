Visual journey

A Blink for the Sky. Existing plan only. No new pictures.

Repetition flagged: p2–p7. Six spreads stay in flowerpot-corner with the same cast (maya) and the same story object (hidden-star). The action stays in place and the emotional register stays calm.

Object state and the camera do change, so the pages are not blank of story. From p3 through p7 that change is not enough to make a new picture a reader would recognise without the words. The world moves at p8, into the open garden.

Reasons: same-location, same-cast, same-story-objects, in-place-action, same-emotional-register.

Visual arc

Intensity: gentle, because the tone is bedtime.

  • opening. Ordinary world, establishing. p1
  • discovery. Something in the world changes. p2
  • development. Action, feeling, or object state develops. p3, p4, p5, p6, p9
  • turn. A clearer change, kept at the story's own volume. p7, p8
  • climax. The strongest gentle change. p10
  • resolution. A new calm, or a world that has changed. p11

Future page roles

These roles are for the next book, before any picture is drawn. This proof does not recut the current paintings. Only the climax is hero, and only that spread is a double-page picture. p9 is a single right-hand page because it sits just before that hero spread.
